# 智能递归解压工具

拖进去就解到底的 Windows 解压软件：压缩包里还有压缩包就继续解，改了后缀、没有后缀、藏在图片后面的压缩包也能认出来，文件重名时自动改名，**绝不覆盖任何已有文件**。

**[⬇ 下载 SmartRecursiveUnzip.exe](https://github.com/396434758-debug/smart-recursive-unzip/releases/latest)**（单个文件，不用安装 Python，下载后可以自己改回中文名）

---

## 使用前提

- Windows 10 / 11（64 位）
- 电脑上装了 **7-Zip** 或 **WinRAR**。都没有时只能解 zip。

exe 没有数字签名，第一次打开 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。

## 怎么用

- **双击打开**：独立窗口，选好文件夹或压缩包，点「开始解压」。关掉窗口就退出。
- **拖到 exe 图标上**：把文件或文件夹直接拖到 exe 上，打开后会自动加入列表并开始解压。

压缩包解到它旁边的**同名文件夹**里（`A.zip → A\`），然后自动进去找下一层，直到解完。

## 它能做什么

### 一路递归解到底
```
A.zip
  └── B.7z
        └── C.rar
              └── 内容.mp4     ← 自动解到这里
```
支持 zip / 7z / rar / tar / gz / bz2 / xz / zst / cab / iso 等 7-Zip 能处理的格式，分卷包只处理第一卷。

### 自动识别是不是压缩包
不看后缀，看文件内容：
- 改了后缀的（`资料.mp4` 其实是 zip、`xxx.7z删除`）
- 没有后缀的
- 图片或视频后面拼接了压缩包的（图种）

docx、xlsx、apk、jar 这类本身是 zip 格式的正常文件，以及 exe、dll 等程序，不会被拆开。只靠内容认出来的压缩包，解压后一定保留原文件。

### 知道什么时候算解到底
解出来的如果只是又一个压缩包、同一组分卷，或者只带几个 txt / url 广告文件，就继续往里解；如果已经是一堆普通文件（默认超过 3 个），就认为到底了，不再去拆里面自带的资源包。这个数字可以在界面上改，填 0 表示全部拆到底。

### 加密包自动试密码
界面上每行一个密码，按顺序自动尝试，第一行留空表示先试无密码。已内置 28 个常见密码，解开用的密码会显示在日志里。密码不对的包会跳过，不影响其它文件。

### 重名自动改名，不覆盖
```
Same.7z   → Same\
Same.zip  → Same (1)\
```

## 选项

| 选项 | 作用 |
|---|---|
| 伪装扩展名 | 填在这里的后缀，不管内容像不像压缩包，都强制试一次；解不开会改回原名。一般不用填，内容识别已经能认出大多数伪装包 |
| 最大递归深度 | 防止压缩包无限嵌套，默认 25 层 |
| 普通文件超过几个就算解到底 | 默认 3，0 = 不限制 |
| 还原伪装文件名 | 伪装包解开后，把文件名改回原来的 `.mp4` / `.jpg` |
| 快速预检 | 伪装扩展名的文件先看开头是不是 zip，明显不是就跳过 |
| 解压成功后删除原压缩包 | 默认关闭，开启前请确认 |
| 跳过已解压过的文件 | 记住解压过的文件，重复点「开始」不会再解一遍。关掉后不会生成记录文件 |

选项改了立即保存，下次打开还是你上次的设置。设置保存在 exe 旁边的 `config.json`，解压记录保存在 `已解压记录.json`，不会在你的文件夹里留下任何东西。

## 注意

- 解压是**原地**进行的，输出文件夹就建在压缩包旁边。
- 解压中途直接关掉窗口会立即退出，可能留下解了一半的文件夹；原压缩包只有在解压成功后才会被删除。
- 程序只在本机 `127.0.0.1` 内部通信，不联网。

## 自己打包

需要 Python 3.10+：

```bat
py -3 -m pip install pyinstaller pywebview
py -3 -m PyInstaller --onefile --windowed --name SmartRecursiveUnzip --add-data "web;web" --add-data "open_folder.ps1;." JieYa.py
py -3 -m unittest test_recursive -v
```

| 文件 | 说明 |
|---|---|
| `JieYa.py` | 主程序：解压引擎 + 窗口 |
| `web/index.html` | 界面 |
| `open_folder.ps1` | 「打开目标文件夹」时把资源管理器切到前台 |
| `test_recursive.py` | 自动测试 |
