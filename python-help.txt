============================================================
  [错误] 没有找到可用的 Python 3.8+
============================================================

为什么会出现这个提示？
  如果你在命令行输入 python 会弹出「微软商店」，那说明系统里
  只有商店的占位空壳（一个 121 字节的假文件），并不是真的装了
  Python。本程序已经能自动跳过这种空壳，所以出现本提示意味着
  这台电脑上确实没有可用的 Python。

怎么解决（任选其一即可）：

  方法一 · 安装 Python（推荐）
    1. 打开 https://www.python.org/downloads/
    2. 下载 Python 3 的 Windows 安装包并运行
    3. 安装第一屏，务必勾选底部的
       [x] Add python.exe to PATH
    4. 装完后重新双击「启动.bat」即可

  方法二 · 关掉商店占位别名
    打开「设置 - 应用 - 高级应用设置 - 应用执行别名」，
    把下面两项关掉：
       python.exe
       python3.exe
    如果你另外装了 Python，关掉别名后它就能被正常找到了。
