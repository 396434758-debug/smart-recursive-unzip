1选择要处理的文件夹 / 压缩包

可添加多个目标。压缩包会解压到与自己同名的子文件夹里（如 game.7z → game\）； 如果该文件夹已存在，会自动改成 game (1)\，绝不覆盖任何已有文件。

2选项

伪装扩展名（逗号分隔）
这些后缀的文件会被改名成 .zip 后强制尝试解压；失败会自动改回原名，文件不会有任何损失。
最大递归深度

普通文件超过几个就算解到底

加密压缩包密码
每行一个密码，按顺序自动尝试；第一行留空表示先试「无密码」。成功的密码会显示在日志里。
